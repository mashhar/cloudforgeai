═══════════════════════════════════════════════════════════════════════════════
STEP 1: INITIALIZE GIT REPOSITORY
═══════════════════════════════════════════════════════════════════════════════

cd /Volumes/SSD/apps/CloudForgeAI
git init
git add .
git commit -m "Initial commit: CloudForge AI v1.0.0

- AI-powered cloud architecture generator
- Google Gemini integration with model fallback
- React Flow interactive diagrams with auto-layout
- Supabase authentication (Email + Google OAuth)
- PostgreSQL database with Row Level Security
- Export to PNG, PDF, Terraform, and JSON
- Responsive UI with dark/light mode theme
- Complete history management
- Production-ready Next.js 15 application"

git branch -M main

═══════════════════════════════════════════════════════════════════════════════
STEP 2A: DEPLOY TO GITHUB (Using GitHub CLI - RECOMMENDED)
═══════════════════════════════════════════════════════════════════════════════

# Install GitHub CLI (if not installed)
brew install gh

# Authenticate with GitHub
gh auth login

# Create repository and push
gh repo create cloudforge-ai --public --source=. --remote=origin --push

# Open in browser
gh repo view --web

═══════════════════════════════════════════════════════════════════════════════
STEP 3: DEPLOY TO PRODUCTION (Choose One Platform)
═══════════════════════════════════════════════════════════════════════════════

─────────────────────────────────────────────────────────────────────────────
OPTION 1: VERCEL (RECOMMENDED)
─────────────────────────────────────────────────────────────────────────────

# Via CLI:
npm install -g vercel
vercel login
vercel --prod

# Via Web:
# 1. Visit https://vercel.com/new
# 2. Import your GitHub repository: cloudforge-ai
# 3. Add environment variables (see below)
# 4. Click "Deploy"

─────────────────────────────────────────────────────────────────────────────
OPTION 2: NETLIFY
─────────────────────────────────────────────────────────────────────────────

npm install -g netlify-cli
netlify login
netlify init
netlify deploy --prod

─────────────────────────────────────────────────────────────────────────────
OPTION 3: RAILWAY
─────────────────────────────────────────────────────────────────────────────

npm install -g @railway/cli
railway login
railway init
railway variables set GEMINI_API_KEY=your_key
railway variables set NEXT_PUBLIC_APP_URL=https://your-app.up.railway.app
railway variables set NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
railway variables set NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key
railway up

═══════════════════════════════════════════════════════════════════════════════
ENVIRONMENT VARIABLES (Required for All Platforms)
═══════════════════════════════════════════════════════════════════════════════

GEMINI_API_KEY=your_gemini_api_key_here
NEXT_PUBLIC_APP_URL=https://your-production-domain.com
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...your_supabase_anon_key

Get API Keys:
- Gemini API: https://aistudio.google.com/app/apikey
- Supabase: https://supabase.com → New Project → Settings → API

═══════════════════════════════════════════════════════════════════════════════
STEP 4: SUPABASE DATABASE SETUP
═══════════════════════════════════════════════════════════════════════════════

1. Create a new project at https://supabase.com
2. Go to SQL Editor
3. Copy and run the SQL from: supabase/schema.sql
4. Enable Email authentication (Authentication → Providers)
5. Get your credentials (Settings → API)

═══════════════════════════════════════════════════════════════════════════════
STEP 5: POST-DEPLOYMENT CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════

1. Update Supabase Redirect URLs:
   - Supabase Dashboard → Authentication → URL Configuration
   - Site URL: https://your-production-domain.com
   - Redirect URLs: Add https://your-production-domain.com/auth/callback

2. Update Google OAuth (if using):
   - Google Cloud Console → Credentials
   - Add authorized redirect URI: https://xxx.supabase.co/auth/v1/callback

3. Test your deployment:
   - Visit https://your-domain.com
   - Sign up / Sign in
   - Generate an architecture
   - Test exports

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Build fails:
  rm -rf .next node_modules
  npm install
  npm run build

Environment variables not working:
  - Verify in platform dashboard
  - Redeploy after changes
  - Check for typos

Database connection fails:
  - Verify Supabase credentials
  - Check project is not paused
  - Restart Supabase project
